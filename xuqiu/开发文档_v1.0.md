### 二.1 架构分层

```
main.c (装配层)
├── board.c (板级)   ──> oled_spi / max98357 / w25q128 (设备层)
├── app_wifi.c (业务) ──> wifi_prov.c ──> wifi_manager (组件)
│                            └── esp_wifi / esp_event / nvs_flash
└── ui.c (界面) ──> font_service + font_render + oled_spi
```

`app_wifi.h/.c` 的职责是**事件回调转发** —— 把 `wifi_prov` 的事件翻译为 UI 可用的信号，
后续在 `ui.c` 里接收。`wifi_prov` 负责完整的配网状态机。

| 组件 | 缺陷 | 解决措施 |
| --- | --- | --- |

## 四、编译环境

PowerShell 设置环境变量，`export.ps1`会失败：

```powershell
$env:PYTHONUTF8 = "1"
$env:IDF_TOOLS_PATH  = "C:\esp\v6.1-rc1\tools"
$env:ESP_ROM_ELF_DIR = "C:\esp\v6.1-rc1\tools\esp-rom-elfs\20241011\"
# 其余自动从系统 IDF_PATH 继承
```

> 系统注册表里没有 `IDF_TOOLS_PATH` / `ESP_ROM_ELF_DIR`，必须手动设；
> 否则 `export.ps1` 会去 `~/.espressif` 扑空报 `tool has no installed versions`。

## 五、实施细则

### 5.1 分区表

当前 `CONFIG_PARTITION_TABLE_SINGLE_APP=y`，app 分区 1 MB，固件 237 KB。
加字库 752 KB → 989 KB，溢出。

改 `sdkconfig`：
```
CONFIG_PARTITION_TABLE_CUSTOM=y
CONFIG_PARTITION_TABLE_CUSTOM_FILENAME="partitions.csv"
```

`partitions.csv` 放项目根：
```csv
# Name,   Type, SubType, Offset,  Size,   Flags
nvs,      data, nvs,     0x9000,  0x5000,
otadata,  data, ota,     0xe000,  0x2000,
app0,     app,  ota_0,   0x10000, 0x200000,
app1,     app,  ota_1,   0x210000,0x200000,
littlefs, data, littlefs,0x410000,0xC00000,  # ~12MB 日志
fatfs,    data, fat,     0x1010000,0x200000,  # 2MB 导出
reserved, data, 0xff,    0x1210000,0xEF0000,
```

### 5.2 WiFi 配网

调用顺序：

```c
// app_wifi.c
void app_wifi_init(void)
{
    wifi_prov_set_callback(on_wifi_event, NULL);   // 注册业务回调
    ESP_ERROR_CHECK(wifi_prov_init());             // NVS + 组件 + 事件
}
```

`wifi_prov.c` 内部：
1. NVS 初始化
2. 注册 `WIFI_EVENT` / `IP_EVENT` 监听
3. 构造 `wifi_manager_config_t` ：重试 5 次 → `WIFI_CONFIG_MODE_WEB`
4. 调用 `wifi_manager_init(&cfg)` ——**组件内部自动判断** NVS 有无配置：
   - 有 → STA 直连
   - 无 → SoftAP + Web 配网 + DNS 拦截

### 5.3 Captive Portal DNS 拦截

位于 `d:\components\wifi_manager\src\captive_portal.c`（已实现），
`wifi_webserver_start()` 时自动调用 `captive_portal_start("192.168.4.1")`。

原理：UDP/53 答复任意查询为 AP IP + HTTP 302 重定向到首页。

### 5.4 STT/TTS

| 环节 | 方案 | 实现方式 |
| --- | --- | --- |
| 唤醒 | ESP-SR 离线 | 官方组件 |
| STT | 在线 | `esp_http_client` POST 音频到 ASR 接口 |
| TTS | 在线 | `esp_http_client` GET 语音流，用 I2S 播放 |

暂未确定第三方接口。

### 5.5 `main.c` 标准范例

```c
void app_main(void)
{
    ESP_LOGI(TAG, "=== ESP32-S3 智能语音终端 ===");
    board_log_pinout();     // 1. 打印接线
    board_init_devices();   // 2. 初始化外设
    app_wifi_init();        // 3. 启动配网
    ESP_LOGI(TAG, "初始化完成");
}
```
